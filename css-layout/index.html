CSS 布局笔记：从盒模型到 Flex 与 Grid

发表于2026-09-28|更新于2026-10-08|前端
|浏览量:

写静态页面的第一天就会遇到一个问题：为什么元素的位置和我想的不一样？
答案通常藏在盒模型和文档流里。这篇笔记把 CSS 布局的主线梳理一遍。

二、文档流、块级与行内

  • 块级元素（div、p、h1）：独占一行，宽度默认撑满父元素
  • 行内元素（span、a、strong）：同一行排列，宽高由内容决定
  • 行内块（inline-block）：同一行排列，但可以设置宽高

脱离文档流的方式有 float 和 position: absolute/fixed ——
它们会让元素不再占据原来的位置，这也是当年 float 布局需要 clearfix 的原因。

三、Flex：一维布局

Flex 解决的是一行或一列内部如何分配空间的问题。
给父元素加一句 display: flex，子元素立刻变成可伸缩的”项目”。

几个最常用的属性：

属性 作用于 常见取值
flex-direction 主轴方向 row / column
justify-content 主轴对齐 flex-start / center / space-between
align-items 交叉轴对齐 stretch / center / flex-start
flex 子项伸缩比例 1 / 0 0 auto
gap 项目间距 任意长度

四、Grid：二维布局

Flex 一次只能管一个方向，Grid 可以同时管行和列。

这四行实现了一个响应式卡片网格 —— 屏幕宽就多排几列，屏幕窄就自动换行，
完全不需要写媒体查询。这在以前要靠浮动 + 百分比 + @media 才能凑出来。

五、选择器与优先级

选择器 写法 权重
标签 p 1
类 .card 10
ID #header 100
内联 style="..." 1000

优先级高的胜出；同权重时后写的胜出。!important 能强行覆盖，但能不用就不用 ——
它会让后面的样式无从下手，是样式表失控的常见起点。

六、小结

一个实用的决策顺序：

  1. 需要一行/一列内部分配空间 → Flex
  2. 需要同时控制行和列 → Grid
  3. 只是简单文字排版 → 直接用文档流，别上布局

布局工具是为解决问题存在的，不是越新越好。能用文档流解决的，就别加 display: flex。
