命令行

几个跨平台都能用、且值得记住的：

命令 作用
pwd 当前在哪个目录
ls -la 列出所有文件（含隐藏文件）
cd - 回到上一个目录
cat file 打印文件内容
grep -r "关键词" . 递归搜索
curl -I <url> 只看 HTTP 响应头

curl -I 这个尤其好用 —— 查一个网站返回的 HTTP 版本、状态码、缓存策略，
一条命令就够了：

输出里的第一行会告诉你协议版本，例如 HTTP/2 200。

效率小习惯

  • 写 Markdown 而不是 Word —— 纯文本，任何编辑器都能开，还能直接进 Git
  • 一个项目一个仓库 —— 别把所有作业塞进一个 repo，历史会乱成一团
  • 提交信息写清楚”做了什么” —— 三个月后的自己会感谢现在的你
  • 定期 git status —— 提交前确认没有把密钥、大文件误提交进去

小结

工具的价值不在于多，而在于不用想就能用。挑一套顺手的，把它练成肌肉记忆，
剩下的精力才留给真正难的问题。
